# Todo Reminder Bot

Telegram-бот для ведення списку завдань з щоденними нагадуваннями о 13:00.

## Структура проекту

```
todo-list-reminder/
├── bot.js                 # Основний файл бота
├── ecosystem.config.js    # Конфіг PM2
├── package.json
├── .env                   # Токен бота (не комітити!)
├── .env.example
├── data/
│   ├── todos.json         # База завдань (авто-створюється)
│   └── users.json         # Активні користувачі (авто-створюється)
└── logs/                  # Логи PM2 (авто-створюється)
```

## Встановлення

**1. Отримай токен бота**

Створи бота через [@BotFather](https://t.me/BotFather) у Telegram і скопіюй токен.

**2. Встанови залежності**

```bash
npm install
```

**3. Налаштуй `.env`**

```bash
cp .env.example .env
# Відредагуй .env і встав свій BOT_TOKEN
```

**4. Встанови PM2 (якщо не встановлено)**

```bash
npm install -g pm2
```

**5. Запусти бота через PM2**

```bash
pm2 start ecosystem.config.js
pm2 save           # Зберегти список процесів
pm2 startup        # Автозапуск при перезавантаженні (виконай команду яку він виведе)
```

## Управління через PM2

```bash
pm2 list                    # Список процесів
pm2 logs todo-bot           # Логи в реальному часі
pm2 logs todo-bot --lines 100  # Останні 100 рядків логів
pm2 restart todo-bot        # Перезапустити
pm2 stop todo-bot           # Зупинити
pm2 delete todo-bot         # Видалити з PM2
```

## Команди бота

| Команда | Дія |
|---------|-----|
| `/start` | Активує бота. З цього моменту щодня о 13:00 надходитиме нагадування |
| `/stop`  | Зупиняє нагадування. Завдання зберігаються |
| `/list`  | Показує поточний список завдань |

## Кнопки інтерфейсу

| Кнопка | Дія |
|--------|-----|
| ➕ Додати | Бот просить ввести текст → зберігає завдання |
| 🗑 Видалити | Показує список із чекбоксами → вибираєш → підтверджуєш |
| 📋 Список | Показує весь поточний список |

## Логіка роботи

### Додавання завдання
1. Натискаєш **➕ Додати**
2. Бот питає: "Введи текст завдання"
3. Надсилаєш текст
4. Бот зберігає і підтверджує

### Видалення завдань
1. Натискаєш **🗑 Видалити**
2. Бот показує список із кнопками-чекбоксами (⬜️ / ✅)
3. Натискаєш на завдання щоб вибрати/зняти вибір
4. Натискаєш **🗑 Підтвердити** — завдання видаляються
5. Або **❌ Скасувати** — без змін

### Щоденне нагадування
- Щодня о **13:00 (Kyiv time)** бот надсилає весь список завдань
- Надсилається тільки активним користувачам (тим хто зробив `/start`)
- Якщо список порожній — нагадування не надсилається

## База даних

Дані зберігаються у простих JSON файлах у папці `data/`:

**`todos.json`** — масив завдань:
```json
[
  {
    "id": "1714041600000",
    "text": "Купити продукти",
    "createdAt": "2024-04-25T13:00:00.000Z"
  }
]
```

**`users.json`** — активні чати:
```json
{
  "active": [123456789, 987654321]
}
```

## Логування

Бот логує:
- Старт/зупинку бота
- Активацію/деактивацію користувачів
- Додавання завдань
- Видалення завдань
- Відправку щоденних нагадувань
- Помилки polling та мережі

Логи PM2 знаходяться у `logs/out.log` та `logs/error.log`.
